Role Overview

Spagad Technologies is seeking an exceptional, high-velocity Software Developer to spearhead the next evolutionary tier of our healthtech and enterprise fintech platforms across Ghana and the broader West African economic zone.

In this role, you will architect resilient distributed systems, build responsive customer-facing web applications, and collaborate with medical practitioners, compliance officers, and fintech partners. You will champion clean code architecture, automated testing suites, and low-latency API layers handling high-volume localized financial micro-transactions.
