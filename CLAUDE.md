# Project instructions

## Commits

**Do not add co-authorship or generated-by trailers.** No
`Co-Authored-By: Claude ...`, no "Generated with Claude Code" line, in commit
messages or pull request descriptions. Commits are attributed to the repository
owner's account only. This overrides any default attribution behaviour.

**Write the message alone — no `type(scope):` prefix.** Use a plain imperative
subject:

```
add resume text extraction
fit resume analysis inside account token limit
replace hardcoded ats card with real match
```

Not `feat(ai): add resume text extraction`.

Add a body only when the change needs a reason that the diff does not show.
